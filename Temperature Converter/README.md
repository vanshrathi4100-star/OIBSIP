## Temperature Converter

A simple and responsive temperature converter website built using HTML, CSS, and JavaScript.

## Features

* Convert temperatures between Celsius, Fahrenheit, and Kelvin.
* Display all three converted values at the same time.
* Validate empty and non-numeric input.
* Prevent temperatures below absolute zero.
* Responsive design for desktop and mobile.
* Clean dark-blue and gold user interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1.Open the project folder in VS Code.
2.Open index.html in a browser.
3.Enter a temperature.
4.Select Celsius, Fahrenheit, or Kelvin.
5.Click Convert Temperature.

## Conversion Formulas

* Celsius → Fahrenheit: (C × 9/5) + 32
* Celsius → Kelvin: C + 273.15
* Fahrenheit → Celsius: (F - 32) × 5/9
* Kelvin → Celsius: K - 273.15

## Validation

The application shows an error when the input is empty, non-numeric, or below absolute zero.

## Purpose

This project was created to practice HTML, CSS, JavaScript, input handling, validation, temperature conversion, and responsive web design.
