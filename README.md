## WebCraft Studio Landing Page

WebCraft Studio is a simple and modern landing page created for a web development project. The website focuses on providing clean, responsive and user-friendly web solutions.

## Features

• Clean and modern landing page
• Responsive design for desktop and mobile
• Navigation menu with Home, Features, About and Contact sections
• Hero section with background image
• Features and services cards
• About section
• Contact section with email button
• Social media links
• Simple and user-friendly layout

## Technologies Used

• HTML5
• CSS3

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html in your browser.
4. You can also use the Live Server extension in VS Code.
